# 安全政策

## 中文版

### 报告漏洞

我们重视所有安全问题的报告。如果您发现 ZeroClaw Desktop 的安全漏洞，请通过以下方式报告：

github issue

我们承诺在收到报告后 48 小时内回复，并在 7 天内提供初步评估。

## English Version

### Reporting a Vulnerability

We take all security issues seriously. If you discover a security vulnerability in ZeroClaw Desktop, please report it as follows:

github issue

承诺在收到报告后 48 小时内回复，并在 7 天内提供初步评估。

## 中文版：漏洞披露政策

我们遵循协调的漏洞披露政策：

1. 安全研究人员报告漏洞
2. 我们确认并评估漏洞
3. 开发和测试修复
4. 发布安全更新
5. 公开披露细节

## English Version: Vulnerability Disclosure Policy

We follow a coordinated vulnerability disclosure policy:

1. Security researchers report vulnerabilities
2. We confirm and assess the vulnerability
3. Development and testing of fixes
4. Release of security updates
5. Public disclosure of details
